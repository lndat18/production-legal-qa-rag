\section*{Projects}
\vspace{2pt}

\href{https://github.com/lndat18/production-legal-qa-rag}{\textbf{Vietnamese Legal QA -- Production RAG}}
\hfill \href{https://github.com/lndat18/production-legal-qa-rag}{github.com/lndat18/production-legal-qa-rag}

\vspace{2pt}

\begin{itemize}[topsep=0pt, itemsep=2pt]
    \item Built an end-to-end RAG chatbot over 6 Vietnamese labor, insurance and tax laws (2,228 structure-aware chunks) that answers with Article/Clause citations, replacing manual legal text lookup
    \item Designed a hybrid retrieval pipeline: dense + BM25 with Reciprocal Rank Fusion, HyDE, citation-aware candidate search, optional MMR, and a local Vietnamese GPU reranker
    \item Added a fail-closed verification layer (deterministic citation and number checks + an independent LLM evidence judge, at most one repair): on the 157-question testset it refused 9\% of cases lacking supported evidence and repaired 12\% before release
    \item Engineered serving reliability: Redis answer/retrieval cache with single-flight, admission control, per-user rate limits, conversation follow-up handling, and throttling across multiple Groq API keys
    \item Shipped an OpenAI-compatible REST API (FastAPI) with an OpenWebUI chat interface, deployed on a single host with Docker Compose and Cloudflare Tunnel, automated backups, Langfuse traces and Prometheus/Grafana metrics, and a GitHub Actions CI running 1,700+ tests with Ruff and mypy
    \item Built a RAGAS evaluation pipeline: generated 203 synthetic cases, reviewed them down to a 157-question golden testset (142 single-hop, 15 multi-hop), and scored Context Precision 0.90, Context Recall 0.87, Faithfulness 0.83 and Answer Relevancy 0.43, with checkpointed, resumable runs that handle API quota limits
    \item[] {\footnotesize
        \textbf{LLM \& Retrieval:} LangChain, Groq (gpt-oss-120b, gpt-oss-20b), Hugging Face, Pinecone, BM25, PyTorch \\
        \textbf{Backend \& Deployment:} Python, FastAPI, Redis, PostgreSQL, OpenWebUI, Docker, Cloudflare Tunnel \\
        \textbf{Observability:} Langfuse, Prometheus, Grafana \\
        \textbf{Evaluation \& CI/CD:} RAGAS, pytest, Ruff, mypy, GitHub Actions}
\end{itemize}
