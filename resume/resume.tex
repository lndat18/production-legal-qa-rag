\section*{Projects}
\vspace{2pt}

\href{https://github.com/lndat18/production-legal-qa-rag}{\textbf{Vietnamese Legal QA -- Production RAG}}
\hfill \href{https://github.com/lndat18/production-legal-qa-rag}{github.com/lndat18/production-legal-qa-rag}

\vspace{2pt}

\begin{itemize}[topsep=0pt, itemsep=2pt]
    \item Built an end-to-end RAG chatbot answering Vietnamese labor, insurance and tax-law questions with article-level citations over 6 legal documents (2,228 chunks), replacing manual legal text lookup
    \item Preserved legal structure from ingestion to answer: converted \texttt{.docx} laws to structured Markdown and chunked by Article/Clause/Point with breadcrumbs, so every passage stays identifiable and citable
    \item Designed a hybrid retrieval pipeline: dense + BM25 with Reciprocal Rank Fusion, HyDE, citation-aware candidate search, optional MMR, and a local Vietnamese GPU reranker
    \item Added a fail-closed verification layer (deterministic citation and number checks + an independent LLM evidence judge, at most one repair) that refuses to answer when evidence is not supported
    \item Engineered serving reliability: Redis answer/retrieval cache with single-flight, conversation follow-up handling, admission control, per-user rate limits, and throttling across multiple Groq API keys
    \item Shipped an OpenAI-compatible FastAPI service with an OpenWebUI chat interface, deployed on a single host with Docker Compose and Cloudflare Tunnel, with automated backups
    \item Instrumented every turn with Langfuse traces and Prometheus/Grafana metrics
    \item Built a RAGAS evaluation pipeline: generated 203 synthetic cases, reviewed them down to a 157-question golden testset (142 single-hop, 15 multi-hop), and compared MMR on/off with checkpointed, resumable runs that handle API quota limits
    \item Enforced code quality with pytest, Ruff, mypy and GitHub Actions CI, with a written spec for every pipeline stage
    \item[] {\footnotesize
        \textbf{LLM \& Retrieval:} LangChain, Groq (gpt-oss-120b, gpt-oss-20b), Hugging Face, Pinecone, BM25, PyTorch \\
        \textbf{Backend \& Deployment:} Python, FastAPI, Redis, PostgreSQL, OpenWebUI, Docker, Cloudflare Tunnel \\
        \textbf{Observability:} Langfuse, Prometheus, Grafana \\
        \textbf{Evaluation \& CI/CD:} RAGAS, pytest, Ruff, mypy, GitHub Actions}
\end{itemize}
