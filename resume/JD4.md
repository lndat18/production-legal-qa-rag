## About the job

Our client is a Fortune 500 technology, defense and engineering leader building an enterprise-grade Agentic AI practice to automate complex workflows at global scale.

This is a production AI role, not a chatbot role.

Role: Agentic AI Engineer / AI Agent Architect

What You'll Build:

You will design, build and ship production-grade Autonomous AI Agents that reason, plan, and act to automate real enterprise workflows across IT, Operations, Finance and other business functions. Your agents will go beyond chat - they will retrieve secure enterprise knowledge, orchestrate tools and APIs, and execute actions with human-in-the-loop governance.

You will work on a multi-platform Agentic AI stack: Microsoft Copilot Studio, Google AgentSpace, AWS Bedrock Agents, and Dataiku AI Agents - building interoperable agents that meet enterprise security, compliance and observability standards.

Key Responsibilities:

* Architect & Build Agentic Systems: Design autonomous agents with reasoning, planning, memory, tool orchestration, and human-in-the-loop workflows for production use.
* Multi-Platform Agent Development: Develop and deploy agents using Copilot Studio, AgentSpace, Bedrock (Agents, Knowledge Bases, Guardrails), and Dataiku - adapting patterns across ecosystems.
* Enterprise RAG & Knowledge Systems: Build secure, scalable RAG pipelines with vector databases, embeddings, hybrid search, and role-based access control (RBAC) for enterprise knowledge retrieval.
* Agent Ops & Evaluation: Own the full lifecycle from POC to production - implement evaluation frameworks, monitoring, observability, prompt optimization, and continuous improvement for reliability and latency.
* Responsible & Secure AI: Implement governance, audit trails, security policies, content filtering, and safe action execution for AI-driven automation.

Tech Stack You Will Work With:

Agentic Frameworks: Microsoft Copilot Studio, Google AgentSpace, AWS Bedrock Agents, Dataiku | LLMs / SLMs | Vector DBs (Pinecone, OpenSearch, pgvector) | RAG, GraphRAG | Tool Calling / Function Calling / MCP | LangGraph, Semantic Kernel | Python

Requirements:

* 3+ years in Software Engineering with 1+ years hands-on in GenAI / LLM Application Development
* Proven experience building Agentic AI / AI Agents beyond simple chatbots - e.g., agents that take actions, use tools, hybrid LLM + ML systems
* Hands-on experience with at least one enterprise agentic platform: Microsoft Copilot Studio, Google AgentSpace, AWS Bedrock, or Dataiku
* Strong experience with Vector Databases, Embeddings, and Production RAG
* Proficient in Python and API / tool orchestration
* Fluent in English with ability to work in a global enterprise environment
